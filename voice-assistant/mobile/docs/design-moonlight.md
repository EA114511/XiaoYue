# 界面设计系统「月夜 · 明珠」— 移动端版

> 小玥 AI 语音助手 Android App 设计规范
> 继承网页版设计语言，针对移动端小屏优化
> 实现代码见 `mobile/src/`

---

## 1. 设计概念

「玥」是传说中的明珠。移动端设计延续**语音即主角**的理念：

- **顶部舞台**：玥珠光球居视觉中心，状态动词与实况字幕紧随其下
- **中部对话流**：最近对话以卡片形式呈现，去气泡化，颜色区分声部
- **底部操作区**：大录音按钮 + 连接状态，拇指可达
- **环境层**：星野背景（星辰 + 月轮 + 极光），营造「月夜」氛围

### 移动端适配原则

| 原则 | 说明 |
|------|------|
| **单手操作** | 核心交互（录音按钮）置于底部，拇指自然触及 |
| **语音优先** | 录音按钮最大化，文本输入弱化 |
| **信息层级** | 光球 > 状态 > 对话 > 操作 |
| **安全区** | 刘海屏/挖孔屏/底部 Home 条避让 |

### 字体

| 角色 | 字体栈 | 大小 |
|------|--------|------|
| 品牌/状态动词 | `Noto Serif SC`, `SimSun` | 24-28px |
| 正文/消息 | 系统无衬线栈 | 14-16px |
| 印章/徽章 | `Noto Serif SC` | 13-18px |
| 英文标签 | 系统无衬线，大写 | 10-11px，字间距 0.2-0.35em |

### 材质

- **暗色玻璃**：`backdrop-filter: blur(14px)` + 低透明墨蓝底
- **发丝线**：1px 金/蓝低透明度线条，替代卡片边框
- **内发光**：`box-shadow: inset` 柔和光晕
- **禁止**：卡片套卡片、厚重阴影、高饱和度色块

## 4. 玥珠状态机

光球是助手之「身」，四种状态各有专属动效：

| 状态 | 触发条件 | 视觉表现 |
|------|---------|---------|
| 待机 `idle` | 默认 | 缓慢呼吸（缩放 ±3%），微光涟漪 |
| 聆听 `listening` | 录音中 | 外环泛青瓷色，粒子加速旋转 |
| 思索 `thinking` | 处理中 | 粒子高速旋转，光晕收缩 |
| 应答 `speaking` | 播放中 | 内核脉冲，光晕扩散 |

### 状态颜色语义

- **聆听**：外环 `#9FD4CB`（青瓷）
- **应答**：内核 `#E4B56A`（暖金）
- **待机/思索**：中性暖金

## 5. 组件规范

### 5.1 顶栏（TopBar）

```
┌─────────────────────────────┐
│ [玥]    小玥            ⚙️  │
└─────────────────────────────┘
```

- **玥印章**：36×36px，圆角 10px，金色描边 + 渐变底
- **标题**：Noto Serif SC，18px，字间距 0.15em
- **设置按钮**：40×40px，触摸区域 ≥44px

### 5.2 光球（VoiceOrb）

**结构**：
```
┌─────────────────┐
│   外层光晕       │  ← radial-gradient 扩散
│  ╭─────────╮    │
│ │ 粒子轨道   │   │  ← 16 颗粒子，Canvas 绘制
│ │  ╭─────╮  │   │
│ │ │核心光球│  │   │  ← CSS 径向渐变
│ │  ╰─────╯  │   │
│  ╰─────────╯    │
└─────────────────┘
```

**参数**：
- 直径：160px
- 粒子数：16 颗
- 光晕：200px 扩散范围
- 动画：呼吸 4s 周期

### 5.3 消息卡片（MessageCard）

**助手消息**（暖金）：
```
┌────┬────────────────────────┐
│ 玥 │ 消息内容...             │
│    │                    14:32│
└────┴────────────────────────┘
```

**用户消息**（青瓷）：
```
┌────────────────────────┬────┐
│ 消息内容...             │ 用 │
│ 14:32                  │ 户 │
└────────────────────────┴────┘
```

- 圆角：14px
- 边框：1px 发丝线
- 背景：渐变（品牌色 12% → 4%）
- 印章：28×28px，品牌色描边

### 5.4 录音按钮（VoiceButton）

**结构**：
```
    ╭─────╮
   │  🎙️  │  ← 80px 圆形
    ╰─────╯
   [按住说话]  ← 13px 标签
```

**状态**：
- 待机：金色边框 + 渐变底
- 录音：青瓷填充 + 脉冲环
- 处理：灰色 + 旋转加载

**触摸反馈**：按下缩小 95%

## 6. 环境层

### 星野（NightSky）

- **星辰**：60 颗，上半部分布，随机闪烁
- **月亮**：右上角，半径 25px，带光晕
- **极光**：底部渐变（青瓷 → 暖金），透明度 3%

### 动效原则

- 全部动效服务于状态表达
- 遵循 `prefers-reduced-motion: reduce`
- 中文排版禁用斜体

---

## 7. 移动端特有规范

### 安全区适配

```css
/* 顶部刘海屏 */
padding-top: calc(12px + env(safe-area-inset-top));

/* 底部 Home 条 */
padding-bottom: calc(24px + env(safe-area-inset-bottom));
```

### 触摸优化

- 最小触摸区域：44×44px
- 按钮间距：≥8px
- 避免边缘手势冲突（iOS 返回手势）

### 性能优化

- Canvas 按 `devicePixelRatio` 缩放（上限 2x）
- 粒子数限制：16 颗（移动端性能考虑）
- 动画使用 `requestAnimationFrame`

## 9. 与网页版差异

| 维度 | 网页版 | 移动端 |
|------|--------|--------|
| 布局 | 双栏 | 单栏（上下） |
| 光球 | 420px，24 颗粒子 | 160px，16 颗粒子 |
| 输入 | 输入坞 + 文本框 | 大按钮（语音优先） |
| 对话 | 完整列表 | 最近 3 条 |
| 导航 | 顶部标签 | 底部操作区 |
| 组件库 | 自定义 | Vant 4（按需） |
